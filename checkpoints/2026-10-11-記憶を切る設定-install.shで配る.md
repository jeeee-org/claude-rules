# 2026-10-11 記憶を切る設定：install.shで配る

- 別のPJ（CTCの技術検証の手元のリポ）で、ハーネスの要件（記憶の統治）を学ぶ中で、Claude Codeの文書を確かめた。auto memoryは手元のセッションでは既定でオンで、指示ファイルは「文脈であって強制される設定ではない」と書かれている。共通ルール§6の「memoryは使わない」は指示なので、守られる保証が無い（実際、そのセッションの指示にはmemoryの書き方が載っていた）。

- README：ファイルの表に`settings/memory.json`の行、「日付ごとの一回限りの手当て」に2026-10-11の項（他のPCの当て方・既存の`true`は手で直す・溜まったmemoryは残る）。
