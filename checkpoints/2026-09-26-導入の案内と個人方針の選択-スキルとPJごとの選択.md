# 2026-09-26 導入の案内と個人方針の選択 — スキルとPJごとの選択

## 依頼
- ルールはAIを使って入れるので、AIがオプションを案内しながら入れられればよい（スクリプトのオプションは覚えていられない）。
- 個人の運用は、PJごとに入れる時にどれを入れるか選ばせる。
- コミットの書き方・memoryを使わない・AI署名を付けない・外に出す文面でMarkdownを使わない・応答の書き方は、選択にせず全版で必須。
- 途中で指摘：PJのほうは`AGENTS.md`に統一する話だったのに、`@AGENTS.md`で繋ぐ形にしたのか。

## やったこと

### 個人の運用を選択肢にした
- `tools/build-rules.py`に`OPTIONS`を置いた：`autocommit`（commitを指示を待たずに行う）・`autopush`（pushを自動で行う）・`worktree`（§5.1）・`toolname`（§5.2の禁止①）。
- 正本の§5・§5.1・§5.2・§7を`<!-- if:… -->`で囲んだ。選ばなかった時の文は次のとおり。
  - 自動commitを選ばない → 「commitはユーザーの指示で行う」
  - 自動pushを選ばない → 「pushはユーザーの指示があった時だけ」
  - worktreeを選ばない → §5.1ごと消え、§5冒頭の「§5.1・§5.2は全PJ必須」とpush先の文からも§5.1が消える
  - ツール名を選ばない → 禁止①が消える
- グローバル版は全部入りなので、生成物（`rules/global-rules.md` / `rules/codex-global-rules.md`）は1バイトも変わっていない（`--check`で確認）。
- 必須の5つは条件を付けていないので、どの版にも必ず入る（テストで確認）。

### 書き込みの道具
- `--options a,b` / `none` / `all`で選ぶ。**初回に省くと止まり、選べる一覧を出す**（黙って既定を入れない）。
- 選択はマーカー行に`選択 autopush,worktree`の形で残る。2回目以降は`--options`と`--target`を省くと、前回の選択と書き込み先を引き継ぐ。
- `--list-options`で一覧を出す（スキルはここから選択肢を作る。書き写さない）。

### `AGENTS.md`への統一（指摘を受けて直した）
- 最初の版は、`both`で`CLAUDE.md`が無くても作り、そこから`@AGENTS.md`で繋いでいた。統一の方針とずれていた。
- 改めた形：PJのルールは`AGENTS.md`だけに置き、`CLAUDE.md`は作らない。Claude Codeはv2.1.277以降、`AGENTS.md`を直接読む。
- 既に`CLAUDE.md`がある時だけ、その先頭に`@AGENTS.md`を足す（`CLAUDE.md`があるとClaude Codeが`AGENTS.md`を読まなくなるため）。
- スキルは、`CLAUDE.md`のPJ固有の指示を`AGENTS.md`へ移したあと、`CLAUDE.md`を消して統一するか（推奨）を聞く。
- 本文の`both`向けの1行も「`AGENTS.md`に統一する。`CLAUDE.md`は作らない」に改めた。

### 案内のスキル `install-rules`
- `skills/install-rules/SKILL.md`。入れ方（グローバル／1つのPJ）→ グローバルならinstall.shの3つの選択 → PJなら状態の確認（更新・選び直し・取り除く）、読み手、個人の運用（複数選択）→ 試しに実行 → 本実行 → 知らせの説明 → 上限の確認 → commitは確認を取る。
- Claude CodeはAskUserQuestionを使い、使えない環境では番号付きで聞く。
- 置き場は3つ。
  - `install.sh`が`~/.claude/skills/`と`~/.codex/skills/`へコピーする
  - リポの`.claude/skills/install-rules`と`.agents/skills/install-rules`はsymlinkにした。cloneしただけのPCでも、このリポでAIを開けば使える
  - このリポで`claude -p`に聞き、スキルが見えることを確かめた（グローバルへ入れる前）

### テスト
- `tools/tests/test_embed_rules.py`へ7件を追加した。
  - 初回に選ばないと止まる
  - 知らない名前は止まる
  - 選んだものだけが入り、必須は常に入る
  - 何も選ばないと代わりの決まりが入る
  - 2回目は前回を引き継ぐ
  - 選び直すと入れ替わる
  - 一覧が出る
- `both`で`CLAUDE.md`を作らないことも確認する。
- 全233件が通過した。

- `init-rules`の2枚は2枚のまま。
