# 2026-09-18 進行中の作業カードの導入

別PCから出た改善案（`IMPROVEMENTS.md` 2026-09-18の項目）を、Claude / Codex 両方のルールと両方の`init-rules`へ反映した。

## 何を変えたか

**`rules/global-rules.md`（10,204→11,548B・残り2,788B）**
- §1の表：`REQUIREMENTS.md`の役割を「決めたこと（要求・方針・決定・スコープ・未決事項）と**進行中の作業カード**（§4）」に、書く時に「**依頼された時**」を追加。
- §1の表・§2：checkpointのファイル名を`YYYY-MM-DD-作業内容.md`から`YYYY-MM-DD-作業名-中身.md`へ。作業名はカードの見出しと同じ語にし、`checkpoints/*-作業名-*`で複数日ぶんを一括して引けるようにした。粒度の言い方も「作業のまとまりごとに1ファイル」から「1日1作業1ファイル」へ。
- §3「タスク実行中」の先頭：作業を頼まれたらまずカードを立ててから動く（その場で終わる用事には立てない）。
- §4の末尾：カードの形（何をする／叶っている状態／現在地／待ち／作業ログ）をコードブロックで固定。現在地は上書きし履歴を積まない。終わったらカードを消して`PROGRESS.md`の完了へ1行＋checkpointリンク。

**`rules/codex-global-rules.md`（9,271→10,614B・残り3,722B）** — 同内容をCodexの文体（太字を使わない）で§1の表2行・§2・§3「実行中：」・§4の末尾へ。

**`skills/init-rules/SKILL.md`** — `REQUIREMENTS.md`の雛形を丸ごと差し替え。節の並びを「目的・スコープ → 進行中の作業 → やること/バックログ → 要求・方針 → 未決事項」に変えた（セッション開始時に真っ先に読むものを上へ）。雛形にあった英数字と日本語の間の半角スペース3箇所（§9違反）も同時に解消。

**`skills/codex-init-rules/SKILL.md`** — 手順3の`REQUIREMENTS.md`の説明にカードを追加。

## 提案に無かったが直したもの

両方の`init-rules`が、checkpointの雛形の説明文で古いファイル名の書式`YYYY-MM-DD-作業内容.md`を指したままだった（Claude版は手順3の雛形直後の注記、Codex版は手順3の`checkpoints/`の行）。**新規PJを立ち上げるスキルが古い書式を教える**状態になるので、同じ書式へ揃えた。

## 受け取った文面の欠落と復元

貼られた提案のうち4箇所が途中で欠けていた（変更1⑤の最終段落・変更2①の表2行・変更2③・変更4）。Claude版とCodex版が同内容の対になっているため、無傷な側から復元して先に適用し、あとから正しい文面を受け取って照合した。**3箇所は復元と一字一句一致**し、変更1⑤の「（ここが膨れたら、その分をcheckpointへ逃がす）」だけが違っていたので差し替えた。差し替え後のバイト数は提案の予測値（11,548B / 10,614B）と完全に一致。

## 積み残し

`tools/migrate-checkpoints.py`とREADMEの説明が`YYYY-MM-DD-作業内容.md`のまま。改名の対応表は人が埋めるので道具自体は動くが、候補名の出し方と文言が古い書式を指す。`migrate-rules`にも既存PJへカードを新設する手順が無い。`REQUIREMENTS.md`の未決事項へ上げた。
