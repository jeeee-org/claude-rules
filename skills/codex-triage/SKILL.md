# Triage

分類前に `${CODEX_HOME:-$HOME/.codex}/hooks/triage-rubric.txt` を全文読み、その正本に従って依頼を分類する。ファイルが見つからない場合は基準を推測せず、インストール不備を一言伝える。

分類結果を1行で示してから、正本が定める分類に対応した進め方を選ぶ。Codex版 quorum/cadence が利用可能なら使用または提案し、未導入ならその旨を一言述べて通常のCodex機能で代替する。

出力形式：

```text
トリアージ: T1 — <短い理由>
```

CADENCEの場合：

```text
トリアージ: CADENCE / <フロー名> — <短い理由>
```

ユーザーが分類だけを求めた場合は判定と理由だけ返す。「分類してから進めて」など実行も求めた場合は、判定後にタスクを続行する。ユーザーが利用フローを明示した場合はその指定を優先する。quorum/cadenceが未導入なら、利用不能であることを一言述べ、通常のCodex機能で代替して進める。
