# 完了条件（このループが何をもって終わるか）

> 統括役が最初に読む。雛形のままだと、統括役は着手前にユーザーへ聞く。
> 公式の勧め: 終わりの状態は1つの測れる形で書き、どう確かめるかを添え、途中で変えてはいけないものも書く。

- **終わりの状態** = （例）`docs/loop/requirements.md`の全受け入れ条件がテストで確かめられ、`npm test`が0で終わる
- **確かめ方** = （例）`.claude/loop/gates/test.sh`が合格する
- **変えてはいけないもの** = （例）公開APIの形、既存のテストファイル
- **範囲の外** = （例）UIの見た目の変更
